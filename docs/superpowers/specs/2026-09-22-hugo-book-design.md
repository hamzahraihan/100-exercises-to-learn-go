## 1. Goal

Publish a free, non-commercial HTML book on GitHub Pages that mirrors the 100
shipped exercises (15 sections, `exercises/*/*/README.md`) in Mainmatter's
learn-by-doing shape (concept → Task → Check), generated from the exercises so
the two can never drift.

## 3. Mechanics

- Layout: new top-level `book/` (`hugo.toml`, `content/`, `static/`,
  theme via Hugo modules, e.g. relearn/learn). `book/content/<section>/`
  holds `_index.md` + `NN_name.md` per exercise. Generated files carry a
  `DO NOT EDIT — generated from exercises/` header. `book/content/` is
  committed (reviewable diffs) and regenerated by the tool below.
- Generator `tools/bookgen` (stdlib Go, `go run ./tools/bookgen`): walks
  `exercises/<section>/NN_name/README.md`, takes title from first `# H1`,
  `weight` from the `NN` numeric prefix (section weight from section prefix),
  emits front-matter + body + footer (link back to exercise dir + global
  attribution line). Fails loudly on missing README, missing H1, bad prefix,
  or duplicate weight.
- Hugo config: title `100 Exercises to Learn Go`, `baseURL`
  `https://hamzahraihan.github.io/100-exercises-to-learn-go/` (from `origin`), book theme with left-sidebar nav,
  goldmark code highlighting for Go. Local dev: generate then
  `cd book && hugo serve`.
- Deploy: new `book.yml` workflow (existing `ci.yml` untouched). On push to
  `main`: setup-go + setup-hugo extended → `go run ./tools/bookgen` →
  `hugo --minify` in `book/` → deploy `book/public` to Pages. Pull requests:
  generate + `hugo --minify` build-check only, plus a no-diff check that
  committed `book/content` matches generator output.

## 4. Contracts (standing rules)

- Exercises stay canonical: `<name>.go` + `<name>_test.go` + `README.md`
  triplet unchanged; book never edits exercise content.
- Generator deterministic and idempotent; `go vet` clean; unit-tested
  (`weight` parsing incl. `00` welcome pages, front-matter escaping,
  idempotency on all 100 files).
- Attribution on every book page footer: inspired by Mainmatter's course
  (link + CC BY-NC 4.0 link), "all Go prose original, free non-commercial
  use", plus per-page link to its `exercises/...` source dir.
- No commercial use (no paywall, sale, or ads) — a CC BY-NC condition.

## 5. Process

Spec (this file) → writing-plans implementation plan → implement
(generator + hugo scaffold + workflow) → review. Ends with green
`ci.yml`, green `book.yml` build, and `hugo --minify` output containing
all 15 sections / 100 pages.

## 6. Non-goals (v1)

No PDF/ePub (HTML on Pages only per decision), no custom `wr`-style CLI
runner, no theme fork, no exercise content changes except review-driven
fixes, no commercial distribution.
