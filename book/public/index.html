    100 Exercises to Learn Go

    Learn Go by doing — one small exercise at a time, from syntax to a working HTTP ticket API. Free for personal and classroom non-commercial use.

    Each exercise lives in exercises/<section>/NN_name/ with a lesson (README.md), a stub to fix (.go), and a test (_test.go) that must pass:

    go test ./exercises/01_intro/01_syntax/ -v

    Solutions live on the solutions branch. This book’s pages are generated from the exercise READMEs — the exercises are the source of truth.

    Inspired by Mainmatter’s 100 Exercises to Learn Rust (CC BY-NC 4.0). All Go prose here is original.
