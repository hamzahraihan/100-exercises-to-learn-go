# Strings

Text is bytes with opinions. Splitting messy input, trimming hostile
edges, asking yes-or-no questions, replacing every occurrence, building
without quadratic cost, and crossing the text-number border in both
directions — six lessons mapping the `strings` package plus `strconv`,
with the runes lesson's bytes-versus-characters split echoing throughout.
