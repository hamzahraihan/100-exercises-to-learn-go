# Intro

Before Go, the workshop. Nobody learns a language in an environment they
can't operate — so this section builds yours first: the test loop every
exercise runs on, the syntax every stub is written in, packages and
imports, and the two tools (`gofmt`, `go vet`) that keep code honest.
Short lessons, permanent habits.
