# Persistence

Survive restarts. Memory forgets; disks (mostly) don't — but only through
discipline this section makes explicit: atomic saves that crashes can't
halve, boot loads that welcome missing files, corrupt files survived with
locating errors, backups written as promises, imports validated like
border crossings. Durability as a set of habits, not a database.
