# Interfaces

Behavior without inheritance. Go's signature idea — small interfaces,
satisfied implicitly — arrives here alongside its younger sibling,
generics: `Stringer` and embedded interfaces for abstraction, type
parameters and constraints for reuse without duplication, `any` and type
switches for the dynamic edges. This is the section the rest of the course
quotes most.
