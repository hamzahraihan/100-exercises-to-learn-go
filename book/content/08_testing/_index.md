# Testing

Prove it. By now you've *run* a hundred tests; this section teaches you to
*write* them with intent: tables that collect evidence, named subtests for
debugging one branch, helpers that locate themselves, fixtures the
toolchain ignores, examples that double as documentation, benchmarks that
measure instead of assuming, and error assertions that pin both branches.
Placed here deliberately — late enough that every shape feels familiar,
early enough to use for everything after.
