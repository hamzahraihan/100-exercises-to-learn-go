# I/O

Streams and files. The two one-method contracts (`Reader`, `Writer`) plus
the tools that make them practical — scanners for tokens, whole-file calls
for small payloads, streaming copies for large ones — composed at the end
into an append-only JSON log. The section's capstone uses nearly every
lesson before it, on purpose.
