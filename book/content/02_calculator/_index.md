# Calculator

Numbers with consequences. A calculator is the smallest program where real
Go semantics bite — integer widths that refuse to mix, loops with one
keyword, overflow that wraps silently, floats that truncate before you
convert, runes hiding inside bytes. Every lesson here breaks something
small and safe, so the ticket system later inherits programmers who have
seen each failure once already.
