# Capstone

The whole band. A ticket API assembled from course parts — store and mux,
create and list, single reads, updates, deletes — then the production
concerns that surround any server: graceful shutdown, environment config,
and an end-to-end suite driving the lifecycle over a real socket. If every
earlier section did its job, this one should feel like recognition, not
discovery.
