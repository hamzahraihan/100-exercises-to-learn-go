# Frameworks

Beyond stdlib. Six lessons porting the ticket API to Gin: routing, path params, JSON binding, versioned groups, middleware, and one error envelope for every failure. Same shapes as the HTTP section — now with `gin.Context`, `ShouldBindJSON`, and `AbortWithStatusJSON`. Learn when the framework pays for itself, and when ServeMux is enough.
