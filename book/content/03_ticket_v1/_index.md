# Ticket v1

Give the domain a shape. Two loose strings become a `Ticket` struct, and
the section follows that type into adulthood: validation methods,
constructors that reject at birth, pointer versus value receivers, zero
values that work uninitialized, string representations, and embedding for
reuse. By the end, a ticket is no longer data you hope about — it's a type
the compiler checks.
