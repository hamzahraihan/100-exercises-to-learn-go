# HTTP

Serve the tickets. Ten lessons from first handler to structured errors,
deliberately ordered so the testing ritual lands *before* the endpoint
that needs it: handlers and statuses, queries and routing, the recorder
pattern, JSON in and out, middleware layers, cancellation, the client
side, and one error envelope for every failure. The capstone assumes this
whole section cold.
